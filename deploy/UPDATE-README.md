**সাইট:** http://dreammart.digitalwebars.xyz/

> এটা **আপডেট** প্যাকেজ — নতুন ইনস্টল নয়। আগের বার যা আপলোড করেছিলেন সেটা **মুছবেন না**।
> শুধু এই zip টা `public_html`-এ extract করলে পরিবর্তিত ফাইলগুলো পুরনোগুলোর উপরে বসে যাবে।

## ধাপ ১ — ফাইল আপলোড

1. cPanel → **File Manager** → **`public_html`** ফোল্ডারে ঢুকুন
2. উপরে **Upload** → `dreammart-update-2026-07-30.zip` আপলোড করুন *(মাত্র ২ MB, দ্রুত হবে)*
3. File Manager-এ ফিরে **Reload** চাপুন
4. zip ফাইলটার উপর **রাইট ক্লিক → Extract**
5. Extract-এর জায়গা যেন **`/public_html`** থাকে (অন্য কোনো সাবফোল্ডার নয়)
6. **"ফাইল আগে থেকে আছে, বদলে দেব?"** জিজ্ঞেস করলে **হ্যাঁ / Overwrite** দিন — এটাই দরকার
7. Extract শেষ হলে `dreammart-update-2026-07-30.zip` ফাইলটা **ডিলিট করে দিন**

### যে ফাইলগুলো বদলাবে

```
public_html/
├── index.html                    ← বদলাবে
├── assets/                       ← নতুন JS/CSS যোগ হবে
│   └── uploads/
│       ├── site-settings/        ← ফুটারের লোগো + ব্যানার (নতুন)
│       └── category-images/      ← ২টা ছবি (নতুন)
└── backend/
    ├── routes/api.php            ← বদলাবে
    ├── database/migrations/      ← ২টা নতুন ফাইল
    ├── database/seeders/         ← বদলাবে
    └── public/_update.php        ← নতুন (ধাপ ২-এ লাগবে, পরে ডিলিট)
```

> **যেগুলোতে হাত পড়বে না:** `backend/.env` (আপনার ডাটাবেসের তথ্য), `backend/vendor/`,
> `backend/storage/` (আপলোড করা ছবি, লগ), আর অ্যাডমিন থেকে আপলোড করা সব ছবি।
> ডাটাবেসের কোনো ডাটাও মুছবে না।

## ধাপ ২ — ডাটাবেস আপডেট (জরুরি)

নতুন পলিসি পেজ আর ফুটারের ঠিকানা/ফোন ডাটাবেসে বসাতে হবে। **SQL ইমপোর্ট করতে হবে না** —
ব্রাউজারে নিচের লিংকটা খুললেই কাজ হয়ে যাবে:

### 👉 http://dreammart.digitalwebars.xyz/backend/_update.php?token=dm-2026-07-30-f3a91c

পেজটা নিজে থেকেই —

- Laravel-এর পুরনো ক্যাশ মুছে দেয় (না মুছলে নতুন কোড চালু হতো না)
- নতুন ২টা migration চালায়
- শেষে ডাটাবেসে মিলিয়ে দেখে সব ঠিকঠাক বসেছে কিনা, আর ✅/❌ দিয়ে দেখায়

**উপরে সবুজ "আপডেট সফল হয়েছে" লেখা আসলেই কাজ শেষ।**

> `token` ছাড়া লিংকটা কাজ করে না, তাই কেউ ভুল করে খুলে ফেললেও কিছু হবে না।
> তবু **সবুজ দেখার পর `public_html/backend/public/_update.php` ফাইলটা ডিলিট করে দিন।**

> migration দুইবার চললেও সমস্যা নেই — আপনি অ্যাডমিন প্যানেল থেকে পেজের লেখা বা
> ঠিকানা/ফোন হাতে বদলে থাকলে সেগুলো **আর ছোঁয়া হয় না**, আগের মানই থাকে।

## সমস্যা হলে

**সাইট পুরনো চেহারাতেই আছে**
ব্রাউজার ক্যাশ। **Ctrl + F5** চাপুন, বা ব্রাউজারের ছদ্মবেশী (incognito) উইন্ডোতে খুলে দেখুন।

**ফুটারে নতুন লিংক নেই, কিন্তু বাকি সব ঠিক**
ধাপ ২-এর লিংকটা খোলা হয়নি। খুলে সবুজ বার্তা আসা পর্যন্ত অপেক্ষা করুন।

**`_update.php` খুললে 404 আসে**
Extract ঠিক জায়গায় হয়নি। File Manager-এ দেখুন
`public_html/backend/public/_update.php` ফাইলটা আসলেই আছে কিনা।

**`_update.php` লাল ❌ দেখাচ্ছে**
লাল লাইনের পাশের লেখাটা কী বলছে দেখুন — বেশিরভাগ সময় ডাটাবেসের পাসওয়ার্ড বা
ফোল্ডার permission-এর কথা লেখা থাকে। ঐ লেখাটাসহ জানালে ঠিক করে দেওয়া যাবে।

**সব ভেঙে গেছে, আগেরটায় ফিরতে চাই**
আগের সম্পূর্ণ প্যাকেজ `dreammart-cpanel.zip` আর `digita42_dreammart.sql` এই ফোল্ডারেই
আছে — `INSTALL-README.md` অনুযায়ী সেটা আবার বসালেই ৩০ জুলাইয়ের আগের অবস্থায় ফিরে যাবে।

## এই প্যাকেজটা যেভাবে যাচাই করা হয়েছে

- হোস্টিংয়ে এখন যে zip আছে তার **প্রতিটা ফাইলের হ্যাশ** মিলিয়ে দেখে ঠিক কোনগুলো
  বদলেছে বের করা হয়েছে — অনুমান করে কিছু নেওয়া হয়নি
- হোস্টিংয়ের আসল ডাটাবেস ডাম্প (`digita42_dreammart.sql`) একটা আলাদা টেস্ট
  ডাটাবেসে বসিয়ে **নতুন migration দুইটা সেখানে চালিয়ে** দেখা হয়েছে — ৪টা পেজ,
  ঠিকানা, ফোন আর লিংক তালিকা সবই ঠিকমতো বসেছে, বাংলা লেখাও ভাঙেনি
- ডেলিভারি চার্জ (৳৭০ / ৳১৫০) সত্যিই ডাটাবেসের `shipping_charges` টেবিল থেকে
  এসেছে কিনা মিলিয়ে দেখা হয়েছে
- নতুন `index.html` যত ফাইল খোঁজে (**১৬৬টা**) তার প্রত্যেকটা extract করার পর
  সার্ভারে থাকবে কিনা যাচাই করা হয়েছে — একটাও বাদ নেই
- প্যাকেজের সব PHP ফাইল `php -l` দিয়ে সিনট্যাক্স চেক করা হয়েছে
